# bamb

Пэт-проект просмотр фотографий на Vue 3

Деплой: https://ofigurovskaya.github.io/bamb/

Описание
Пэт-проект — просмотр фотографий, реализованный на Vue 3 с использованием современного стека технологий. Данные загружаются с бесплатного API JSONPlaceholder. Для корректной работы может понадобиться VPN. Из-за проблем с сайтом https://via.placeholder.com/ фотографии и миниатюры представлены в виде ссылок.


Функционал
•	При загрузке страницы отправляется запрос на сервер за списком фотографий.
•	В таблице реализована сортировка по возрастанию и убыванию по столбцам: id и id альбома — сортировка происходит при клике на заголовок столбца с визуальной индикацией.
•	В поле поиска можно вводить номера альбомов (множественный ввод через пробел), по которым отправляется запрос к API.
•	Поддерживается отправка формы поиска по нажатию Enter.
•	Валидация поля поиска: при неверном вводе отображается сообщение об ошибке.
•	Если поле поиска пустое, загружаются все альбомы.
•	Кнопка переключения темы "Dark Theme" позволяет менять светлую и тёмную тему интерфейса.
•	Список фотографий сохраняется в localStorage для сохранения состояния между сессиями.
•	Шапка таблицы прилипает к верхней части блока и остаётся видимой при прокрутке.


Стек

•	Vue 3 (Composition API)
•	Pinia (управление состоянием)
•	Tailwind CSS (стилизация)
•	Vite (сборка и дев-сервер)


Установка и запуск
1.	Клонируйте репозиторий
2.	Установите зависимости (npm install)
3.	Соберите проект (npm run build)
4.	Для локальной разработки можно использовать (npm run dev)
5.	Откройте в браузере адрес, указанный в консоли (обычно http://localhost:3000 или http://localhost:5173).
